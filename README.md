# Replication Package

This repository contains the replication package for the paper **“Do LLM-Based Agentic Program Repair Systems Really Produce Semantically Correct Fixes? A Systematic Literature Review.”**

## Contents

The repository includes the dataset compiled from the systematic literature review of 44 primary studies (published between 2024 and 2026) investigating agent-based LLM automated program repair (APR) systems. 

## Purpose

This replication package is provided to support transparency, traceability, and reproducibility in software engineering research. It enables readers to inspect the extracted qualitative evidence, examine the categorizations used in answering the research questions, and verify the empirical grounding in agentic program repair.
